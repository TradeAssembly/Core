## Frozen customer outcome

- A new customer installs one pinned unsigned/ad-hoc Core version, signs into
  production Hub, connects Alpaca through agent-initiated browser OAuth, and
  restarts with durable credential custody. No key/config copying, source reading,
  operator-only identity grants, or staging endpoints in the customer setup.
- Their external agent owns orchestration and its continuous loop. Core exposes
  submit/reconcile, deterministic Warden risk/authority, strategy, research,
  backtest, journal, and promotion tools. Preserve the deterministic path;
  agent-driven submission must not depend on scheduler ticks.
- Production Relay is actually purchasable: normal signup/account management,
  approved checkout/return, signed payment webhook, payment-backed entitlement
  and allowance enforcement, enrollment, durable journal/replay/read/export,
  and the promised Watch/Reach operations on custom and direct origins.
- Owner-only staging, tenant/environment isolation, reviewed storage/IAM/secrets,
  and changed-code rollback preserving nonempty data remain required.
- Initial delivery is a public, versioned direct download and tested one-command
  bootstrap. Mac ARM64 is qualified; Windows x64 and GNU Linux x64/ARM64 have
  build/architecture/inventory/license/integrity evidence and are experimental.
  Windows/Linux runtime acceptance is deferred, never represented as passed.
- Preserve the same installation root, state, executable and MCP configuration
  across direct and retained npm installation/upgrade/rollback paths.

Excluded: Apple payment/Developer ID/notarization, Intel Mac, Windows ARM, F3/F4,
new agent runtime, new strategy/risk language, other brokers, UI redesign,
pricing redesign, infrastructure migration, repository visibility changes,
automatic review chains, actual broker orders and production Live activation.
Public Core must not acquire hosted dependencies, credentials or billing.
Do not reopen unchanged M0–M6. Historical M7/M8 and signed-release obligations
are not complete; this release has its own explicit unsigned verdict.

Standing authorization covers necessary in-scope operations, not unlimited
spending, unrelated actions or mandatory human security handoffs. The known
approved Relay offer is $39/month; verify its live identity before any transaction.
